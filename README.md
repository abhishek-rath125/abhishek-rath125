### 🚀 Featured Projects

- **[Buck-Boost PWM Duty-Cycle Demonstrator](#)** — LTspice project showing one power stage behaving as either a buck or a boost converter purely by changing 555-timer PWM duty cycle. Includes the full debugging trail (inverting-topology bug → SEPIC redesign → 555 supply-voltage fix).
- **EchoSight** — AI-powered offline navigation app for visually impaired users, built in React Native/Expo for HackVerse 2026, with an offline fallback mode using MediaPipe and ML Kit.
- **Physical IC Tester** — breadboard-built logic tester using 7474/7476 flip-flops, a 74153 MUX, and 7486 XOR comparators, cross-verified against a Logisim Evolution simulation.
- **Environmental Comfort Score System** — sensor-fusion project combining DHT11 (temperature/humidity), MQ-2 (gas), and LDR (light) readings into a single comfort metric.
